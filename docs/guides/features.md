# 功能概览

> [← 返回文档索引](../README.md)

## 控制台总览

- ✅ **今日活动** - 查看当前活动、开放日常本和推荐操作
- ✅ **模拟器预览** - 概览与日常共用“关闭 / 快照 / 实时”模式和画质，默认关闭；快照每 10 秒刷新，实时默认使用 15 FPS、最长边 640 的省电档
- ✅ **状态汇总** - 聚合当前任务、调度、掉落和养成数据

## 日常任务流程

预览模式和画质会在同一次使用中的页面切换之间保留。重新打开应用默认保持关闭，只有启用“重新打开时恢复预览”才会恢复上次选择。浏览器进入后台时暂停观看和截图，回到前台后按当前模式恢复；连接过程中可以随时关闭或取消启动。截图和连接均有超时处理，截图失败会自动重试，超时的 ADB 截图进程会被终止。画质修改在下次连接或手动重连后生效，帧率可选择 10 / 15 FPS 等低负荷档位。

画质尺寸表示视频最长边，省电档的横屏画面通常为 640×360。触控会等待当前连接的设备尺寸，并按视频与设备的实际方向映射；视频留边不接受新的按下操作，旋转、重连或退出沉浸画面会取消尚未结束的手势。状态中的“网络 RTT”是当前选中 WebRTC 连接的网络往返时间，不含设备响应、编码和播放等待，不能直接代表点击到画面变化的总耗时；浏览器未提供的指标显示为 `--`。

返回、Home 和后台任务按钮在输入通道就绪时通过 WebRTC 发送配对的按下与释放事件，通道尚未就绪时沿用信令 shell 命令。输入发送失败不会再重播 shell 命令，以免重复操作。

最后一位观看者退出后，后端等待 3 秒释放对应的设备 Agent 和编码资源；启动后 15 秒内没有观看者也会释放。其他标签页或上游可识别的直连观看者仍在观看时会继续保留串流。信令与 TURN 服务保持可用，供下次手动连接。高级设置中的“停止服务 / 停止 Agent”会影响使用该服务的其他观看者。

- ✅ **启动游戏** - 自动启动明日方舟客户端，可切换已登录账号；关闭启动开关时只连接运行中的游戏
- ✅ **理智作战** - 支持多关卡，每个关卡独立次数设置
  - 自动替换活动关卡代号（HD-X → OR-X）
  - 日常/芯片本开放日检测（CE-6、AP-5、CA-5、SK-5、LS-6、PR-A/B/C/D）
  - 理智耗尽自动停止后续关卡
  - 支持按“过期天数”使用临期理智药，连战倍率支持 -1~10
  - 支持剿灭作战（Annihilation）
- ✅ **基建换班** - 自动收菜、换班、无人机加速；支持回收站、加工站、训练室与副手换人；自定义换班可编辑 MAA 基建排班表（设施、房间与跳过/保持原样语义）
- ✅ **自动公招** - 自动刷新、选择标签、确认招募；支持 3 星保留招聘许可与多选 Tag 策略，招募次数为 0 时只计算标签
- ✅ **信用收支** - 自动访问好友、收取信用、购买商品
- ✅ **领取奖励** - 自动领取每日、每周、邮件、签到活动等奖励
- ✅ **关闭游戏** - 任务完成后自动关闭游戏

## 定时任务

- 支持多个执行时间点（界面最多 6 个），共用同一份日常流程；修改流程会影响所有时间点
- 关闭定时后保留时间摘要，重新启用即可继续使用
- 实时显示执行状态和进度动画

## 作业与肉鸽

- 支持普通作业、作业集、SSS 作业和悖论模拟
- 支持从链接或关卡名搜索作业
- 支持集成战略（含黑流树海）与生息演算（含重启锚点）等长流程任务；高级参数由模型选择 CLI 或动态任务
- 执行后展示结算与关键结果摘要（楼层/步数/得分、投资、事件、里程碑等），失败时保留可读原因
- 内置辅助诊断：一键检查运行环境、设备连接、资源版本/完整性与任务预检，给出结论与定位信息

### 作业队列与详情

- 作业页只有一个作业列表。「作业队列」负责入队、排序与执行；作业集预览在下方只提供续跑摘要和失败原因，不重复渲染列表，没有预览时不出现摘要空框。队列执行统一使用作业卡顶部的「立即执行」，队列面板不再单独提供「执行队列」按钮。
- 入队来源与展开规则：作业链接加入单个作业，作业集链接把成员展开为队列项；关卡搜索结果的「加入队列」按 URI 加入；本地 JSON 作业文件上传后读取标题、关卡与干员信息加入。同一作业链接只保留一项，队列最多 50 项。
- 队列操作：逐项勾选/取消、上移、下移、删除、清空。队列内容保存在浏览器本地存储并在刷新后恢复；勾选是当前会话状态，刷新后默认全选。
- 执行分两种语义：
  - 当前预览作业集的成员被选中、且队列顺序与计划一致时，走作业集执行（`run_copilot_set`），保留作业集原有的连续/手动逐关语义，逐项状态来自作业集视图。
  - 混合来源、调整过作业集成员顺序或包含本地文件/自定义作业时，走服务端显式作业队列 Run（`run_copilot_queue`）。服务端为每条目单独下发 Copilot 任务，返回待执行/执行中/已完成/失败/已跳过/已终止的逐项状态与失败原因；失败策略 `stop` 首败停止、`continue` 记录失败后继续；手动模式逐项等待「开始下一项」，等待中可「跳过此项」；终态可「重试失败项」，只重新提交失败条目并保持原队列顺序。整个队列属于同一个 Run，刷新或隐藏页面只影响观察，不会自动重跑。
- 详情层：点击队列行主体打开。桌面为右侧非模态抽屉，队列保持可见并能切换其他作业；手机为底部 Sheet。详情展示关卡与关卡 ID、理智、编队方式、突袭适用性、已完成模式、作业链接，以及失败原因和干员需求（精英、等级、技能、模组）与干员组。
- 已知限制：队列执行当前使用一个全局突袭设置，预设编队条目按普通模式执行；选择普通+突袭双模式时队列路径按普通模式执行并提示，需要两种模式时分开提交。本地文件按上传路径与客户端可读元数据展示，不请求 PRTS 预览。队列条目最多 50 项，失败重试只覆盖 `run_copilot_queue` 路径；作业集路径沿用原有重置与续跑语义。

## 数据与养成

- 从 MAA 识别结果解析仓库和干员 Box
- 读取材料数据库和关卡开放日，计算干员精一/精二所需材料
- 维护养成队列，并可将养成计划应用回日常任务流程
- 记录并统计掉落数据

## Telegram 通知

- 手动执行与定时运行都在流程结束后发送
- 任务完成通知（成功/失败/跳过统计）
- 自动截图并发送
- 详细的任务总结（关卡、次数、掉落、耗时）
