# 日志

> [← 返回前端架构](../README.md) · [文档索引](../../README.md)

日志页是统一的日志观察入口。战斗与肉鸽工作区只保留执行状态、进度、终止与设备预览，不创建日志会话，也不提供额外日志入口。

## 页面与交互

| 内容 | 所有者 | 职责 |
| --- | --- | --- |
| 页面壳 | `pages/logs/LogViewer.tsx` | 页头、状态指示与工作区组合 |
| 观察条件 | `features/logs/components/LogsWorkspace.tsx` | 呈现、事件范围、Run 范围、级别、搜索、折叠与导出 |
| 受控面板 | `LogContentModeTabs`、`LogsToolbar`、`HistoryLogPicker` | 控件、键盘导航和用户动作回调；不获取日志 |
| 列表与跟随 | `LogConsole`、`model/logFollow.ts` | 单条详情、滚动容器、跟随与新日志提示 |
| 实时会话 | `model/realtimeLogStream.ts`、`hooks/useRealtimeLogs.ts` | 缓冲、计时器、取消、暂停、本地清屏和覆盖提示 |
| 历史会话 | `model/historyLogSession.ts`、`hooks/useHistoryLogs.ts` | 文件列表、选择、读取与迟到响应裁决 |
| 会话组合与清理 | `hooks/useLogsSession.ts`、`model/logCommands.ts` | 切换来源、历史清理请求与选择协调 |
| 事实与投影 | `types/index.ts`、`model/logModel.ts`、`model/logCallbackSummary.ts` | 保留源记录，派生语义注解、事件选择与重复分组 |
| 导出格式 | `model/logExport.ts` | 从选中的源事实生成文本，不依赖呈现方式 |

### 呈现、选择与详情

默认使用“易读 + 关键事件”。“易读 / 原文”只决定同一批选中事件的文案，不决定事件是否存在；“关键事件 / 全部事件”是独立筛选条件，详细内容在每组记录内展开。

`LogEntry` 保存源事实：采集时间、原级别、源文本、来源、实时信封与可用的 `id`、`sequence`、`runId`、`operationId`。实时解析不会用消息内的 MaaCore 时间或级别覆盖采集信封；历史解析保留完整日期、毫秒、线程前缀与空行，行索引只标识本次文件快照内的位置。

`LogAnnotation` 引用源记录，提供摘要、有效严重度、关键性和解析状态。语义转换不能修改事实，不能降低已有错误或警告；未知回调、未知警告/错误、截断 JSON 与缺字段采用原文兜底。明确识别的常规诊断事件才可默认隐藏。

`buildLogView` 的处理顺序是注解、级别与搜索匹配、关键性选择、重复分组、呈现。工作区只派生一次；列表使用 `visible`，导出使用折叠前的 `selected`。相同筛选条件切换呈现时，事件身份、顺序、数量和导出内容保持一致。

- 搜索不区分大小写，同时匹配摘要、源文本、时间、级别和 Run/operation；关键事件过滤隐藏的搜索命中会提示数量，并提供显示全部事件的动作。
- 级别筛选始终使用有效严重度；详情同时保留原始级别和信封。
- 保持来源顺序，不按时分秒重新排序。
- 重复折叠仅合并连续、源内容与级别一致且 Run、operation、来源相同的记录；分组保存所有成员及各自时间，可逐条展开取证。
- Run 范围默认为全部。显式选定 Run 后，终态、新活动 Run 或窗口淘汰都不自动改变选择；无归属日志不会被挂到当前 Run。历史文件不提供 Run 归属，历史浏览时禁用该选择器，返回实时恢复原选择。

### 导出与清屏

“导出筛选结果”导出当前加载、符合筛选的源记录，保留重复成员；易读/原文呈现与折叠不改变导出内容。实时记录包含采集元数据与源文本，历史记录保留源行；文件名为 `maa-log-<UTC 日期>.txt`。Blob、objectURL 的创建与撤销由工作区负责，空结果禁用导出。

“清屏”只设置当前页面的本地可见边界，不发送清空请求，不删除服务端共享缓冲或历史文件。后续快照不会重新显示已清屏的源记录，暂停状态也不改变。旧服务端缺少事件 ID 时只能按内容降级识别，完全同文的旧记录与新记录无法可靠区分。

`POST /agent/logs/recent/clear` 仍是服务端共享缓冲的维护接口，兼容已有 API 消费者，日志页不调用它。

## 实时流生命周期

### 读取协议与覆盖范围

- `GET /api/agent/logs/recent?lines=200`，客户端每 1250ms 读取最近 200 条；服务端将 `lines` 限制为 1–500。
- 响应仍为数组。每条记录新增进程实例内稳定的 `id` 和递增 `sequence`，淘汰或清空不会重用序号；服务重启使用新的实例身份。
- 每次成功读取整体替换当前窗口，不累计归档。相同源事实和信封保留既有数组引用，避免空轮询驱动列表更新。
- 没有 cursor、since、offset 或按 Run 回读接口；客户端 Run 筛选只作用于已加载窗口。实时缓冲不是完整 Run 归档，MAA 历史文件也不是实时缓冲的备份。
- 有稳定身份时检查相邻快照的连续性；已知序号跳跃或实例变更提示可能有未加载记录。旧服务端或首次打开无法证明覆盖完整性，页面持续说明窗口限制。

### 请求与观察生命周期

同一时刻最多一个在途请求。慢请求期间跳过轮询 tick，不叠加请求；每次请求使用独立 `AbortController`，只有仍为当前且未中止的响应可以提交。失败或非数组响应保留旧缓冲并展示错误，取消不作为失败。

| 事件 | 行为 |
| --- | --- |
| Activity 隐藏/真正卸载 | `stop()` 清计时器并取消在途读取，保留已显示快照 |
| Activity 恢复 | 同步文档可见性后 `start()`，允许读取时立即请求并重建计时器 |
| 文档隐藏 | 取消在途请求；计时器保留但不发送请求 |
| 文档恢复 | 允许读取时立即重读，不等待下一 tick |
| 手动暂停 | 冻结列表并取消在途读取；Activity 和文档恢复都不解除暂停 |
| 手动继续 | 立即读取当前窗口，再按间隔轮询；期间缺失无法回补 |
| 错误重试 | 若暂停则先恢复，再通过同一单在途守卫读取 |
| 进入历史 | 停止实时流并 `reset()` 当前快照、清屏边界与连续性提示；`enabled=false` |
| 返回实时 | 恢复手动暂停，再由 `enabled=true` 立即读取当前窗口 |
| 真正重挂载/刷新 | 创建新实例，观察条件、缓冲、选择与本地边界重置 |

实时日志是会话数据，不进入 TanStack Query，不持久化，也不跨标签页共享。删除工作区日志后无需额外的多观察者管理层。

### 滚动跟随

自动滚动与暂停读取是不同动作。自动滚动关闭时不驱动滚动；开启后位于底部才跟随，用户查看旧内容时不抢位置。跟随归 `LogConsole` 与纯状态机 `logFollow.ts`。

新增检测使用选中事实的事件身份，旧 API 使用内容多重集合降级。同一快照、无关 Run 更新、仅移除旧记录不产生未读；窗口外缺失不可计数，因此统一显示“有新日志”，不声称精确到达总数。点击提示或回到底部恢复跟随，切换观察范围清除旧未读状态；切换呈现不改变事件集合。

## 历史会话与清理

历史文件仍由独立读取生命周期管理，与实时共享事实模型、筛选、分组、详情和导出规则。

| 项目 | 契约 |
| --- | --- |
| 列表 | `GET /agent/logs/files`，服务端按修改时间倒序；路径标识选择 |
| 内容 | `GET /agent/logs/files/:encodedPath?lines=1000`；服务端限制 1–5000 行，文件尾部单次最多读取 2 MB |
| 覆盖 | 文件尾部窗口；不能承诺完整文件或完整 Run |
| 清理 | `POST /agent/logs/cleanup {maxSizeMB:10}`；按服务端规则保留最新文件，确认后刷新列表 |

文件列表与读取各持独立请求序号和 AbortController。新选择、返回实时或 Activity 隐藏会取消旧读取，迟到响应不能覆盖新来源。列表失败保留旧列表并展示独立错误；读取失败保留选择，允许重试或换文件。成功刷新列表会更新选中文件元数据，普通列表缺失不自动退出历史模式。

Activity 隐藏取消进行中的读取并转为 `cancelled`，保留选择与已有内容；恢复重读列表，并只重试被取消的当前文件。已成功或明确失败的文件不在恢复时自动重读。文档隐藏不单独暂停历史请求。

历史清理使用单在途槽位和确认弹层，历史浏览时禁用清理入口。失败不刷新列表或改变选择，弹层保持打开；删除成功后刷新失败仍视为删除成功，由列表展示刷新错误。只有清理确认且列表已成功刷新，才按文件是否存在裁决当前选择。隐藏/卸载只取消本地等待，不能撤销服务端已收到的删除。

模式、级别、搜索与折叠跨来源保留；进入历史关闭并禁用自动滚动，返回实时重新打开。历史结果不会写入实时缓冲。

## 回归与关联

```sh
pnpm --filter la-pluma-next-client exec vitest run src/features/logs src/pages/logs
```

关键不变量包括事实完整保留、未知/错误/缺字段兜底、呈现独立于选择、搜索源文本、分组成员保留、固定 Run 范围、本地清屏、相同快照不报未读、失败保旧、取消与迟到响应、Activity 隐藏恢复，以及历史选择和清理裁决。浏览器集成补充真实导航和 Activity 行为，视觉回归覆盖两种主题与三个视口。
